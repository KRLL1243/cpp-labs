# Лабораторная работа № 3

**Тема: одномерные массивы (числовые последовательности).**

## Общие требования

1. Использовать статический массив; отдельно выполнить задание для динамического массива.
2. Максимальную размерность массива задать именованной константой.
3. Реальное количество элементов массива ввести с клавиатуры с контролем выхода за границы массива. Массив должен содержать не менее одного элемента.
4. Предусмотреть два способа заполнения массива:
   - с клавиатуры;
   - с помощью датчика случайных чисел. Перед заполнением ввести границы интервала, которому должны принадлежать элементы массива.
5. Вывести результаты расчётов. Если по каким-либо причинам решение задачи невозможно, вывести соответствующее сообщение.
6. Дополнительные массивы для преобразования данных использовать нельзя.

## Вариант 5

В массиве, состоящем из n целых элементов, вычислить:

- количество перемен знака (нуль считать положительным числом);
- произведение элементов массива, расположенных между первым и вторым нулевыми элементами.

Преобразовать массив таким образом, чтобы сначала располагались все чётные элементы, а потом — нечётные. Порядок следования элементов внутри каждой группы не изменять.
