# Лабораторные работы по ОИМП

Лабораторные работы на C++ за 2026–2027 учебный год.

- `lab01` — вычисление функций с помощью числовых рядов.
- `lab02` — целочисленная арифметика.
- `lab03` — одномерные массивы.
- `lab04` — матрицы (в работе).

Исходный код расположен в папках соответствующих лабораторных. Условия выполненных вариантов для лабораторных приведены в README внутри этих папок.
