## Определения для этих вариантов

- **Простое число** — натуральное число, имеющее ровно два различных натуральных делителя: 1 и само число.
- **Совершенное число** — натуральное число, равное сумме всех своих делителей, кроме самого себя. Примеры: 6, 28, 496, 8128.
- **Число Армстронга** — N-значное натуральное число, равное сумме N-х степеней своих цифр. Примеры: 153, 370, 371, 407, 1634.
- **Числа-близнецы** — два простых числа, разность которых равна 2. Примеры: (3, 5), (5, 7), (11, 13).
- **Дружественные числа** — два натуральных числа, каждое из которых равно сумме всех делителей другого, кроме самого этого числа. Пример: 220 и 284.
- **Числа Фибоначчи** в условии определены так: `F[0] = F[1] = 1`, `F[i] = F[i−1] + F[i−2]` при `i ≥ 2`.
